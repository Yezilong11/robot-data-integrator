## 2. Proposed Changes

### P0 内容有效性把关（阻断"占位冒充/语义错配/mesh 缺失"继续判成功）

#### P0-A 新增横切语义/内容校验层（R1+R2）
- **文件**：`src/rdi/graph/nodes/validate.py`（新增两个校验函数，接入 `node_validate`）
- **A.1 元数据代理占位检测 `_is_metadata_proxy(item)`**
  - 规则：满足任一即占位代理 →
    1. `item.reference is not None`（P0-4 大文件未下载，仅给 URL）；
    2. `canonical_format == "DatasetSummary"` 且 `data` 为 dict、`file_tree` 为空列表且无任何实际文件内容字段；
    3. 序列化后落盘字节约 < 200B（阈值常量 `_PLACEHOLDER_BYTE_THRESHOLD = 200`）且 `is_fallback=True` 或 `data_source_quality=="fallback"`。
- **A.2 目标-内容语义匹配 `_semantic_mismatch(req, item)`**
  - 仅对 GRASP / MESH / ROBOT_URDF / SIM_CONFIG 四类启用（内容是"指定物体/机器人"语义的关键类型）。
  - 目标 token 集：`req.object_name` + `req.keywords` + `req.description` 中的实体词（复用 `parse_goal._YCB_COMMON_OBJECT_NAMES` 与 `_OBJECT_NAME_PATTERNS` 提取；对已覆盖的 YCB 中文物体名建立映射表，如 苹果→apple、马克杯→mug、香蕉→banana）。
  - 资产标识文本：`item.name` + `item.provenance.source_url` 末尾两段 + `item.data` 中 title/description（前 200 字符）。
  - 判定：目标 token 与标识文本**零重叠** → mismatch（`severity=ERROR`，`message="内容与需求语义不符（目标 X，实际 Y）"`）。
- **A.3 接入 `node_validate`**
  - 对每个 ParsedItem：`_is_metadata_proxy` 为真 → ERROR「需求实际未获得真实数据（仅元数据/占位）」；`_semantic_mismatch` 为真 → ERROR。
  - **取消 `is_fallback` 一刀切跳检**：`_check_loadability` 对 `is_fallback` 项保留格式/加载跳过，但**新增的内容有效性与语义校验对所有项一律生效**（不受 is_fallback 豁免）。
  - `context={"issue_type": "content_validity"}` 供路由与 assemble 复用。

#### P0-B assemble 状态推导把"占位项"视为未满足（R1）
- **文件**：`src/rdi/graph/nodes/assemble.py`
- `node_assemble` 处理 parsed_data 前，按 `state.validation_issues` 中 `context["issue_type"]=="content_validity"` 的 ERROR 对应 req_id 建集合；这些 req 不写入 `manifest_files`，改为追加 `MissingItem`（`reason="内容有效性未通过"`，并附原 mismatch/占位原因），使 `_derive_package_status` 据此把"占位冒充"判为 `partial`（非必需）或 `failed`（REQUIRED），杜绝 0~116B 元数据判 complete。

#### P0-C URDF mesh 缺失显性化（R3）
- **文件**：`src/rdi/adapters/base.py` + `src/rdi/graph/nodes/validate.py`
- `_collect_assets` 中下载失败的资产从 `skipped` 集合写入返回：新增 `RawData.metadata["assets_missing"] = list[str]`（`_download_xml_with_assets` 返回 dict 改为同时填充 metadata；本地路径分支 `_local_assets_from_xml` 同样把本地缺失资产记入）。`RawData.metadata` 已是 dict 字段，无需改模型结构。
- `_validate_urdf_loadability`：在 `raw_bytes` 缺失分支也执行 XML 引用核对（复用 `_missing_urdf_assets`）；并结合 `item.assets` 外的 `assets_missing`（从 ParsedItem 透传，`parse_convert.py` 把 `raw.metadata.get("assets_missing")` 写入 `ParsedItem.warnings` 或 metadata）——缺失 mesh 时判 ERROR「引用的外部资源缺失: …」。

#### P0-D DatasetSkill 消费 markdown 摘要（R4）
- **文件**：`src/rdi/skills/dataset_parse.py`
- 新增 `_parse_markdown(data, kwargs)`：提取首个 `# ` 标题为 title、首个非空段落为 description，`file_tree` 为空，返回 `StandardResult(success=True, is_fallback=True, data_source_quality="fallback", completeness_pct=55, confidence_score=0.6, warnings=["仅数据集摘要（markdown），未下载数据文件"])`。
- `process` 的 `fmt=="markdown"|"md"` 分支接入；`fmt` 未知但内容以 `#`/markdown 特征开头时同样走该分支（覆盖 github README 无显式格式的情况）。
- 效果：github/HF 摘要不再 0 文件；配合 P0-A 占位检测，此类结果在 validate 记为 ERROR/降级，包判 partial 而非伪装 complete。

### P1 检索与解析

#### P1-A validate 重试路由区分"检索轴失败"（R5）
- **文件**：`src/rdi/graph/nodes/validate.py` + `src/rdi/graph/edges.py`
- `node_validate` 在返回的 `validation_issues` 中，对**检索侧无数据**类（`missing` 需求缺失、`result.data is None`）的 ValIssue 增加 `context["issue_type"]="retrieval_axis"`（现有 missing 分支已生成 issue，补 context 即可）。
- `route_after_validate`：当"全部 ERROR 均为 retrieval_axis 且无新增 retry_req_ids"→ 直接返回 `"pass"`（进 assemble 如实报失败），不再空转 3 轮；只有存在内容/语义/可加载性 ERROR 时才 `"retry"`（≤3 轮不变）。
- 效果：R5 类空包从 ~3×源预算耗时收敛到 1 轮；P2_RETRIEVE 不再被误报为"重试后成功"。

#### P1-B 解析偏移修复（R6-①）
- **文件**：`src/rdi/graph/nodes/parse_goal.py`
- 1) `_STRONG_TYPE_KEYWORDS[GRASP]` 增加：`"抓取标签"`、`"抓取标注"`、`"抓取规划"`、`"grasp label"`、`"grasp annotation"`、`"grasp planning"`。
- 2) `_normalize_datareq` 增加**单向消歧**（放在强词循环之前）：`req.req_type == DATASET` 且文本含上述 GRASP 数据内容词 → 改写为 `GRASP`（仅 DATASET→GRASP 单向，不影响"机器人抓取数据集"类 DATASET 语义题）。
- 修复目标：ss_graspnet_004（题设预期 grasp）稳定解析为 GRASP。

#### P1-C LLM 结构化输出容错（R6-② / C 报告 B2）
- **文件**：`src/rdi/intelligence/client.py`
- `call_structured` 校验失败分支：捕获 `ValidationError`，检查 schema 中 `list[str]` 类型字段，若模型输出为逗号/顿号分隔字符串，按 `[，,、;;；\s]+` 拆分转数组后重试一次；仍失败再走原降级。
- 新增单测 fixture 模拟 qwen-max 字符串输出，验证归一化路径（`tests/unit/intelligence/` 若不存在则建 `tests/unit/intelligence/__init__.py` + `test_client_list_normalization.py`）。

## 3. Assumptions & Decisions

- **A1 语义校验用轻量规则**（token 重叠 + YCB 名单），不引入 embedding/新依赖；已知上限：中文泛词可能误判。以 `ponytail:` 注释标注上限与升级路径（后续用 LLM 深度校验替换）。
- **A2 不改 `per_req_timeout=180`**（D4 为 Kinova 完整下载调优过），R5 由路由判定修复而非改预算。
- **A3 DATASET→GRASP 消歧为单向规则**；若后续题设期望"抓取数据集＝dataset 语义"，需在问题集评审确认（本计划按 ss_graspnet_004 题设= grasp 执行）。
- **A4 记录补正/复核/截图属成员动作**，本计划只提供清单与脚本能力，不替成员伪造记录。
- **A5 不新增依赖、不重构未涉 bug 的代码**（遵循 ponytail：最小 diff）。
