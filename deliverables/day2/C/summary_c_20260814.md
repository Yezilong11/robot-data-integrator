### 6.2 arxiv PDF 打开失败（P4_FORMAT，4 轮复现，已解决）——根因与修改方法

#### 具体根因（已定位到代码）

**问题不在 fetch 层，而在下游解析层没配套改。** 整条链路：

```
ArxivAdapter.fetch
  ├─ HEAD 预检 Content-Length > arxiv_max_fetch_bytes(2MB) → 返回 metadata JSON（format=json，不下载）
  ├─ 下载后 _is_valid_pdf 校验（fitz 实际打开验证魔数+结构+页数）
  │    └─ 无效 → 重试一次 → 仍无效 → _metadata_fallback 返回 metadata JSON（format=json）
  └─ 有效 → RawData(format="pdf")
        ↓
parse_convert → SkillRegistry.process_retrieval_result
        ↓ skill.process(raw.data, fmt=raw.format, ...)
PaperSkill.process(data, **kwargs)
        ↓ 忽略 fmt 参数
fitz.open(stream=data, filetype="pdf")  ← JSON 字节当 PDF 打开 → "Failed to open stream"
```

关键代码点：

1. **fetch 层已正确降级**（[arxiv.py](file:///d:/tiaozhanbei/robot-data-integrator/src/rdi/adapters/arxiv.py)）：`_is_valid_pdf` 用 PyMuPDF 实际打开校验（仅查 `%PDF` 魔数不够——国内网络会拿到"魔数正确但结构损坏"的字节），无效时返回 `format=json` 的 metadata（含 url/size/title/abstract）。
2. **解析层未适配 format=json**（[paper_parse.py](file:///d:/tiaozhanbei/robot-data-integrator/src/rdi/skills/paper_parse.py)）：`PaperSkill.process(self, data, **kwargs)` 曾**忽略 `fmt` 参数**，无论 pdf 还是 json，一律 `fitz.open(stream, filetype="pdf")`。而 [registry.py](file:///d:/tiaozhanbei/robot-data-integrator/src/rdi/skills/registry.py) 已传入 `fmt=raw.format`，但 PaperSkill 不消费。
3. **结果**：fetch 降级成 JSON（生产者已改）→ PaperSkill 仍把 JSON 字节当 PDF 打开（消费者没改）→ 报 `无法打开 PDF: Failed to open stream` → manifest `missing_items` 原样记录 → 4 轮复现。

> 一句话：**降级契约（format=json）与解析契约（pdf）不匹配**。只改了生产者，没改消费者。

#### 具体修改方法（ad2581f 已落地）

在 `PaperSkill.process` 增加 `fmt` 分支——当 `fmt == "json"` 时，把 metadata 字节直接装配为成功结果（`canonical_format="json"`），不再走 `fitz.open`：

```python
def process(self, data: bytes, fmt: str | None = None, **kwargs: Any) -> StandardResult:
    if fmt == "json":
        return self._process_metadata(data)   # success=True + is_fallback=True + completeness=60%
    # ... 原有 PDF 打开逻辑 ...
```

配套：`validate` 对 `is_fallback` 结果不把空 text/page_count 判为错误（warning 级）；`_REQ_EXPECTED_FORMATS` 中 PAPER 未列出 → 不校验格式，避免降级 JSON 在装配前被记 MissingItem。

**本轮验证**：ss_arxiv_001 在 ad2581f 下成功落包（`is_fallback=true`，缺失 0，无 ERROR），P4_FORMAT 消除。
