## 六、问题解决方法（建议，待 A 评审）

### 6.1 arxiv PDF 打开失败（P4_FORMAT，3 轮复现）

- **现象**：检索成功（arxiv 命中真实论文），fetch 后 `PaperSkill` 打开 PDF 报 `Failed to open stream`，文件数 0。
- **根因初判**：arxiv fetch 下载的 PDF 在本地不可解析（网络下载内容问题），或 fetch 返回 metadata JSON 后 parse_convert 仍按 PDF 路径处理。
- **建议**：A 裁定 P4_FORMAT 口径；若需修复，复核 arxiv.py fetch 的 PDF 有效性校验（`%PDF` 头检查 + metadata fallback）与 parse_convert 对 `format=json` 的处理分支。

### 6.2 LLM grasp 歧义误判（P1_PARSE，github 已修复、huggingface 仍复现）

- **现象**：`检索 robot grasp dataset`（应 DATASET）仍判 GRASP。
- **建议**：parse_goal prompt 增加「数据集/dataset→DATASET」hint；测试层补充歧义回归用例。
