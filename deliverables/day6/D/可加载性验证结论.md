## 3. 一致性核验（与 record.json 比对）

- 16/16 case 的 `record.json` 中 `loadability` 字段均为 passed，与本次实测一致（**0 冲突**）。

## 4. 异常摘要

- **未发现 failed 项**：16 包全部 URDF 结构、全部 mesh（270+ 文件）、3 个 MuJoCo 场景（panda.xml×2、req_001.xml、req_002.xml）加载与仿真通过。
- **warning 级（1 处）**：ss_mujoco_001（day2 早期包）URDF 内 mesh 引用为 `package://` URI，yourdfpy 无法按 package:// 语义解析（无 package.xml），仅打印 warning；mesh 文件物理随包落盘、trimesh 85/85 可加载。属历史包结构瑕疵，不影响交付可用性（day4 franka P5_RUNTIME 同类问题在 franka_002/003 已修复，现无此问题）。
- **watertight 说明**：URDF 视觉/碰撞网格不要求水密（全部 faces>0）；物体类网格（gs STL、ycb STL、mug STL、robotiq base STL、allegro link_tip）水密；gs_002 含 2 个退化小三角面片致整体 is_watertight=False（主体网格水密，可加载），已在记录如实标注。
- **Isaac Python 场景**：ms_003 sim_config 为 `.py`（Isaac Python），不适用 MuJoCo；静态核验通过（文件存在、资源随包、引用名与落盘一致——day4 资源名回写修复验证）。
