## 3. 异常摘要

- **未发现任何 failed 项**：13+1 个包的全部 URDF 加载、全部 mesh 加载（150+ 个文件）、MuJoCo 仿真全部通过；无 `Unable to resolve filename`、无加载异常。
- **无 MJCF 资产**：13 个 day5 包中 ms_003 的 sim_config 为 Isaac Python（.py），其余包无仿真配置需求；MuJoCo 运行时验证由 day3 的 ms_005（含 2 个 MJCF）覆盖。
- **watertight 说明**：URDF 视觉/碰撞网格（OBJ/DAE）不要求水密，只需可加载且面数>0（全部满足）；物体类网格（google_scanned、EGAD mug、robotiq base STL、allegro link_tip）均 watertight（google_scanned_002 壶为开口物体例外，属正常）。
- **结构一致性**：各包 `manifest.files` 与磁盘实际文件一致，分类目录正确（ms_003 的 sim_config/objects/req_001.stl 与 objects/req_001.stl 内容一致）。

## 4. 结论

**13 个清尾补测数据包 + ms_005 全部可加载、可运行，无验证失败项。** URDF（franka 13/12、robotiq 11/10、allegro 23/22、kortex 11/10）与 Mesh（18/18、10/10、11/11、1/1、9/9、87/87）逐文件加载通过；MuJoCo 场景（ms_005）加载并可推进一步仿真。各 case 的 `record.json` 中 `loadability` 字段与 `runtime_check_detail` 与本结论一致。
