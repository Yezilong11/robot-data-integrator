# Panda Simulator

A PyTorch-based simulation environment for the Franka Emika Panda robot.

## Installation

```bash
pip install -r requirements.txt
python setup.py install
```

Requires a real robot interface for deployment.

## Usage

```python
import panda_simulator
```

## Files

- `setup.py`
- `requirements.txt`
- `panda_description/robots/panda.urdf`
