# 联调问题记录表

> 角色：质量工程师（F）联调问题记录表。

## 使用说明

- 发现问题时立即登记；每条记录必须包含模块、问题描述、根因、责任人和状态。
- 责任人可以写具体名字或角色（如 B/C/D/E/F）。
- 状态流转：`发现` → `修复中` → `已验证` → `关闭`。
- 目前联调阶段优先记录“可复现步骤 + 实际结果 + 预期结果”。
