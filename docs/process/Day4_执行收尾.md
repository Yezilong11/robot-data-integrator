# Day 4：执行收尾

## 当日目标

完成全部既定 case（单源 + 多源交叉），补齐记录与截图，执行进度接近全绿。

## 各角色详细工作

### A（组长/架构师）

1. 完成剩余认领的多源题（如 `ms_007` 未指定仿真器、`ms_008` 单需求）。
2. 复核判定一致性：抽查已判定 case，确认 PASS_WITH_FALLBACK 的降级均显式可追溯。
3. 处理执行分歧的最终裁定，保证口径统一。

### C（数据工程师）

1. 完成数据源类全部单源题，补测遗漏源（如 IEEE 未配 Key 的降级记录）。
2. 交叉多源题全部完成，汇总数据源可用性初稿（基于探活 + 执行观察）。

### D（机器人工程师）

1. 完成格式/仿真类全部单源题。
2. 多源交叉完成，汇总可加载性验证结论（哪些 URDF/Mesh/MJCF 验证不过）。

### E（产品工程师）

1. 完成流程类全部 case，P6_FRONTEND 记录归拢。
2. 确认全员截图规范落地（命名/数量/内容），补不规范截图。

### F（质量工程师）

1. 全量校验记录：字段完整率、截图数量、判定与分类码一致性。
2. 更新进度表至"全部已执行"，列出"未判定/未复核"待办。
3. 统计初稿：PASS/PASS_WITH_FALLBACK/FAIL 分布。
